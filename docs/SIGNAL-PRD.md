# SIGNAL — PRD

| 항목 | 내용 |
|------|------|
| 앱 | SIGNAL — *노이즈는 걸러내고, 진짜 시그널만* |
| 타깃 | 미국 시장과 코인/매크로 흐름을 함께 보는 한국 개인 투자자 |
| 플랫폼 | iOS 우선, Android 병행. Expo SDK 54 / React Native 0.81 |
| 운영 모델 | Signal API 서버가 외부 데이터를 수집·정규화·번역·요약하고, 앱은 Signal API만 조회 |

## 제품 방향

SIGNAL은 단순 뉴스 리더가 아니라 “오늘 무엇을 봐야 하는지”를 알려주는 투자 정보 허브다. 뉴스, 유튜브, 시세, 실적/매크로 일정, 컨콜 데이터를 모아 오늘의 시그널과 관심 브리핑으로 압축한다.

앱의 첫 인상은 원시 피드가 아니라 다음 질문에 답해야 한다.

- 오늘 시장에서 중요한 변화는 무엇인가?
- 내 관심종목 중 지금 확인해야 할 것은 무엇인가?
- 어떤 원문 뉴스/영상/일정이 이 판단을 뒷받침하는가?
- 알림으로 받을 만한 변화인가?

## 현재 제품 범위

| 영역 | 현재 역할 |
|------|-----------|
| 오늘의 시그널 | 서버 인사이트 Job이 생성한 시장 브리핑/자산 시그널. 앱 첫 화면과 전용 리스트에서 날짜별 조회 |
| 관심 브리핑 | 기기 관심종목 전체를 요약하는 개인 대시보드. 오늘 체크포인트, 종목별 사유, 시장/일정 요약 제공 |
| 뉴스 | 글로벌·코인·한국 세그먼트. 서버 수집/번역/해시태그 기반 표시, 뉴스 탭 상단 고정 |
| 시세 | 관심·인기·시총·코인 세그먼트. 서버 수집 quote/coin 데이터를 사용 |
| 유튜브 | 경제 채널 큐레이션. 최신순/인기순 버킷과 조회수 기반 정렬 |
| 종목 상세 | 가격, 뉴스, 실적, 로컬 체크 점수, 해당 티커의 수집 인사이트를 드릴다운 |
| 캘린더/컨콜 | 경제 일정, 실적 일정, 컨콜 트랜스크립트 조회 |
| 알림 | 앱 계정 로그인 기반 알림함. 서버 outbox와 실제 push 수신 기록을 함께 표시 |
| 계정 | 이메일/비밀번호 및 카카오·네이버·구글·Apple 소셜 로그인. SIGNAL 서버 JWT 세션 사용 |
| 설정 | Signal 서버 endpoint, 탭 순서, 테마, 알림, 캐시, 뉴스 표시 선호 관리 |

## 데이터 원칙

- 앱은 Finnhub, YouTube Data, OpenAI, Claude, CoinGecko, Ninjas 같은 외부 provider를 직접 호출하지 않는다.
- 외부 key는 서버 env seed 또는 Admin 설정에서 관리한다.
- 서버 저장소는 SQLite 기능별 테이블이다. 추후 MySQL 전환 시 같은 테이블 경계를 유지한다.
- 공개 조회 API는 가능한 한 전체 DB 스냅샷 대신 필요한 테이블만 직접 조회한다.
- 인사이트와 알림은 원문 소스 링크를 유지한다.

## 인증과 알림

- 앱 사용자 세션은 모든 로그인 방식에서 SIGNAL 서버 JWT access token + refresh session을 사용한다.
- 소셜 provider 토큰은 identity 확인과 연결에만 사용하고 앱 세션으로 저장하지 않는다.
- 약관은 언어/타입/버전별로 관리하고, 가입 시 사용자가 동의한 버전과 시각을 저장한다.
- 알림은 먼저 `notification_items` outbox에 저장된다. worker가 설정된 경우 push provider로 발송하고 결과를 같은 레코드에 기록한다.
- 실제 push 발송 전에는 `mock` provider로 상태 전이를 검증한다.

## 출시 기준

출시 전에는 [RELEASE-CHECKLIST.md](./RELEASE-CHECKLIST.md)를 기준으로 확인한다.

핵심 체크:

- 운영 API/worker 분리와 Railway volume SQLite 경로 확인.
- JWT private key, 소셜 로그인 key, EAS project id, iOS push flag 설정.
- 오늘의 시그널/뉴스/시세/유튜브/알림 주요 API 응답 시간 확인.
- 카카오·네이버·구글·Apple 로그인 실기기 QA.
- 운영 약관/개인정보처리방침 등록.
- AdMob 운영 ID 또는 광고 비노출 정책 결정.
