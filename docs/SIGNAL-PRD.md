# SIGNAL PRD

## 제품 목표

SIGNAL은 사용자가 매일 시장에서 먼저 봐야 할 정보를 빠르게 판단하게 하는 앱이다. 뉴스·영상·시세·캘린더를 단순 나열하지 않고, 관심종목과 연결된 시그널과 근거 콘텐츠를 우선 보여준다.

## 핵심 사용자 가치

- 오늘 시장에서 확인할 포인트를 빠르게 파악한다.
- 관심종목의 움직임, 관련 뉴스, 일정, 영상을 한 흐름에서 본다.
- 원문 근거로 이동해 직접 검증할 수 있다.
- 알림과 오늘의 시그널로 앱 재방문 이유를 만든다.

## 주요 화면

| 화면 | 역할 |
|---|---|
| 홈 | 핵심 시그널, 관심종목, 관련뉴스 요약 |
| 뉴스 | 글로벌/코인/내 관심/영상 피드 탐색 |
| 시세 | 관심종목, 인기, 시총, 코인 가격 확인 |
| 유튜브 | 경제 영상 피드 |
| 더보기 | 브리핑, 캘린더, 컨콜, 계정, 설정 진입 |
| 관심 브리핑 | 관심종목 전체를 시장 요약과 함께 확인 |
| 종목 상세 | 단일 종목의 시세·뉴스·일정·인사이트 확인 |
| 알림 | 사용자별 공지, 인사이트, 계정 알림 확인 |

## 데이터 원칙

- 앱은 Signal Server API만 호출한다.
- 수집과 provider 키 관리는 서버/Admin에서 한다.
- 공개 API 응답은 앱 화면에 필요한 필드만 내려준다.
- 캐시는 탭별 TTL과 수동 새로고침 기준으로 관리한다.

## 운영 목표

- Job 실행 상태와 실패 원인을 Admin에서 명확히 확인한다.
- Postgres/Flyway 기반으로 스키마와 기본 운영 데이터를 명시적으로 관리한다.
- 소셜 로그인은 외부 계정 검증에만 사용하고, 앱 세션은 Signal JWT를 사용한다.
