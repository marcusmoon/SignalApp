# SIGNAL PRD

## 제품 목표

SIGNAL은 사용자가 매일 시장에서 먼저 봐야 할 정보를 빠르게 판단하게 하는 앱이다. 시장 브리핑과 뉴스·공시·시세·캘린더를 단순 나열하지 않고, 날짜·시장(국내/미국) 기준으로 읽기 쉽게 보여준다.

## 핵심 사용자 가치

- 오늘 시장에서 확인할 포인트를 빠르게 파악한다.
- 국내·미국 시장 브리핑을 날짜별·회차별로 한 화면에서 읽는다.
- 관심종목 시세, 관련 뉴스, 일정, 영상을 연결해 본다.
- 원문 근거로 이동해 직접 검증할 수 있다.
- 알림과 시장·뉴스 탭으로 앱 재방문 이유를 만든다.

## 주요 화면

| 화면 | 역할 |
|---|---|
| 홈 | 히어로 1장(오늘 정리 / 장중 브리핑) · **오늘의 키워드**(에이전트 keywords 합산, 없으면 숨김) · 뉴스 흐름 · 일정 칩 · **바로가기** · (오늘만) 시세 · (신선할 때만) 섹터 흐름. 장중 브리핑 전체 회차는 시장 탭. 공시 흐름은 더보기/공시. 보드·시세·뉴스 등은 바로가기 드릴(탭 루트 전환 없음) |
| 뉴스 | 글로벌·한국·코인·IT·YouTube 피드 |
| 공시 | 미국·한국 공시 목록·다이제스트 |
| 시장 | 장중 브리핑(날짜·회차: 미장·장전·장중·마감) |
| 시세 | 관심·인기·시총·코인 가격 |
| 더보기 | 내 정보·공시·섹터·게시판·게임 숏컷 (설정 없음) |
| My info | 환경 설정·내 활동·계정(프로필·소셜·비밀번호·약관) |
| 오늘 정리 상세 | 히어로(오늘 정리) · 푸시 — `app/today-briefing.tsx` |
| 유튜브 | 경제 영상 피드 (뉴스 탭의 Video 세그먼트에서만 접근) |
| 종목 상세 | 단일 종목의 시세·뉴스·일정 |
| 알림함 | 공지·시그널·계정 알림 |

## 데이터 원칙

- 앱은 Signal Server API만 호출한다.
- 수집과 provider 키 관리는 서버/Admin에서 한다.
- 공개 API 응답은 앱 화면에 필요한 필드만 내려준다.
- 캐시는 탭별 TTL과 수동 새로고침 기준으로 관리한다 ([FEED-INTERACTION.md](./FEED-INTERACTION.md)).

## 운영 목표

- Job 실행 상태와 실패 원인을 Admin에서 명확히 확인한다.
- Postgres/Flyway 기반으로 스키마와 기본 운영 데이터를 명시적으로 관리한다.
- 소셜 로그인은 외부 계정 검증에만 사용하고, 앱 세션은 Signal JWT를 사용한다.
