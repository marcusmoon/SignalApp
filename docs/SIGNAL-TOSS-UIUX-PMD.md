# SIGNAL Toss UI/UX PMD

이 문서는 SIGNAL 앱을 Toss 계열 UI/UX로 전면 개편한다고 가정했을 때의 Product / Market / Design 방향을 정리한 실행 문서다. 목표는 단순히 색을 밝게 바꾸는 것이 아니라, 사용자가 매일 앱을 여는 이유를 더 빠르게 인지하고 행동하게 만드는 것이다.

참고 기준:

- Toss Design System: color role, blue primary action, large tap targets, low-noise surfaces
- Toss류 금융 앱 패턴: 홈에서 바로 상태를 요약하고, 상세는 자연스럽게 drill-down
- SIGNAL PRD: “오늘 무엇을 봐야 하는지”를 알려주는 투자 정보 허브

## 1. 결론

Toss식으로 개편하면 SIGNAL은 현재의 “다크 투자 피드 앱”에서 “개인화된 시장 체크 앱”으로 바뀌어야 한다.

핵심 변화:

- 앱 첫 화면은 뉴스 목록이 아니라 **오늘의 투자 체크 요약**이어야 한다.
- 뉴스, 유튜브, 시세는 각각 독립 탭이 아니라 “근거 자료”로 자연스럽게 연결되어야 한다.
- 관심 브리핑과 오늘의 시그널은 별도 개념처럼 보이면 안 된다. 홈에서는 하나의 **오늘 볼 것**으로 묶고, 상세에서 분리한다.
- 다크 테마 중심보다 light-first를 기본으로 두고, dark는 선택 테마로 둔다.
- 카드 중첩, 설명 문구, 작은 보조 버튼을 줄이고, 큰 액션과 명확한 상태를 우선한다.

## 2. 제품 포지션

### 현재 인식

현재 앱은 기능이 충분하지만 사용자가 처음 봤을 때 정보 구조가 이렇게 느껴질 수 있다.

- 뉴스, 오늘의 시그널, 관심 브리핑, 시세가 각각 따로 있다.
- 어느 화면을 먼저 봐야 하는지 사용자가 판단해야 한다.
- “내 관심종목에서 오늘 뭐가 중요한가”보다 “여러 데이터를 탐색한다”에 가깝다.

### Toss식 목표 인식

사용자가 앱을 열면 5초 안에 다음을 알 수 있어야 한다.

- 오늘 시장 분위기
- 내 관심종목 중 지금 볼 종목
- 왜 봐야 하는지
- 관련 뉴스/시세/영상/일정으로 바로 이동하는 길

즉 홈의 질문은 “뉴스 뭐 있지?”가 아니라 **“오늘 내가 확인할 건 뭐지?”** 가 되어야 한다.

## 3. 정보 구조 개편안

### 하단 탭

Toss식 앱은 탭을 많이 늘리기보다 주요 습관 흐름만 남긴다.

권장 탭:

| 탭 | 역할 | 현재 대응 |
|---|---|---|
| 홈 | 오늘의 시그널 + 관심 브리핑 + 주요 근거 | 뉴스 탭 일부 + 관심 브리핑 |
| 뉴스 | 글로벌/코인/영상/내 관심 원문 피드 | 현재 뉴스 탭 |
| 시세 | 관심종목/인기/코인 가격 확인 | 현재 시세 탭 |
| 더보기 | 유튜브, 캘린더, 설정, 계정, 약관 | 현재 더보기 |

유튜브는 매일 핵심 탭이 아니라면 더보기 또는 홈 섹션으로 내려도 된다. 영상 소비 비중이 커진다면 별도 탭 유지가 가능하지만, 출시 초기에는 홈의 보조 근거로 두는 편이 더 명확하다.

### 홈 구조

권장 홈 순서:

1. 헤더: SIGNAL, 알림, 내정보
2. 오늘의 시장 온도
3. 오늘 볼 종목 3개
4. 내 관심 브리핑
5. 관련 뉴스/영상/일정 근거
6. 더 보기 액션

예시:

```text
SIGNAL
오늘 시장은 변동성 확대 구간이에요

[시장 온도 72] [관심종목 3개 주의] [오늘 일정 2개]

오늘 볼 종목
MU  실적 기대와 가격 변동이 같이 커졌어요
AAPL 뉴스 4건, 장전 변동 +2.1%
TSLA 변동성 확대, 최근 뉴스 6건

근거
뉴스  | 유튜브 | 일정
```

## 4. 화면별 설계

### 홈

홈은 “요약 → 이유 → 근거” 순서로 설계한다.

구성:

- 상단 요약 문장 1개
- 시장 상태 pill 2~3개
- 오늘 볼 종목 카드
- 관심 브리핑 요약
- 관련 뉴스/영상/일정 compact list

제거/축소:

- 긴 설명 문구
- 같은 의미의 오늘의 시그널/관심 브리핑 중복 CTA
- 큰 카드가 여러 개 연속으로 쌓이는 구조

### 뉴스

뉴스 탭은 순수한 feed로 단순화한다.

구성:

- 상단 세그먼트: 글로벌 / 코인 / 영상 / 내 관심
- 필터는 플로팅 또는 상단 작은 chip
- 오늘의 시그널은 큰 카드로 반복 노출하지 않는다.
- 새로고침 결과는 toast 또는 얇은 inline notice로 처리한다.

뉴스 카드:

- 제목 2줄
- 출처, 시간, 태그
- 원문 보기
- 관련 시그널이 있으면 작은 pill로 표시

### 시세

시세 탭은 Toss 증권 계열처럼 “관심 리스트”의 가독성이 핵심이다.

구성:

- 관심 / 인기 / 시총 / 코인 segmented control
- 가격과 등락률을 오른쪽에 고정
- 종목명/출처/전일 종가가 겹치지 않도록 높이와 줄 수 고정
- 카드보다는 list row에 가깝게 정리

중요:

- MU처럼 글자와 보조 정보가 겹치는 경우를 막기 위해 row 내부 레이아웃을 `left info`와 `right price`로 완전히 분리한다.
- 등락률 색상은 강하지만 배경은 약하게 둔다.

### 관심 브리핑

관심 브리핑은 현재 기능적으로 중요하지만 배치가 무겁다. Toss식으로는 “오늘 내가 봐야 할 이유”만 남기는 것이 맞다.

구성:

- 오늘 체크포인트 3개
- 오늘 볼 종목
- 이번 주 일정
- 시장 요약

원칙:

- 섹션마다 설명 문구를 두지 않는다.
- 같은 종목이 여러 섹션에 반복되면 “이 종목이 여러 이유로 중요함”을 한 카드 안에 합친다.
- 종목별 카드에는 뉴스/변동/실적/일정 badge를 붙인다.

### 종목 상세

종목 상세는 “시그널요약”과 “오늘의 시그널”이 혼란스럽지 않게 이름을 분리한다.

권장 명칭:

- 상단: 종목 체크
- 서버 인사이트: 수집된 시그널
- 로컬 점수: 체크 스코어

구성:

1. 가격 header
2. 오늘 체크 요약
3. 관련 뉴스
4. 일정/실적
5. 영상/원문 링크

### 내정보

내정보는 Toss식으로 “계정 상태와 활동”만 보여준다.

구성:

- 프로필 요약
- 로그인 수단
- 알림 설정 상태
- 내 활동: 알림함, 시그널, 브리핑
- 약관/로그아웃/탈퇴는 하단 text link 수준

원칙:

- 서비스 정보 박스 제거
- 계정 상태와 보안 설정을 분리
- 위험 액션은 작게, 하단에 배치

## 5. 비주얼 시스템

### Light-first 토큰

현재 `constants/theme.ts`는 다크 중심이다. Toss식 개편은 light-first 토큰을 추가하고 dark는 선택 테마로 분리해야 한다.

권장 토큰:

```ts
export const SIGNAL_LIGHT = {
  primary: '#3182F6',
  primaryDim: '#EAF3FF',
  bg: '#F7F8FA',
  card: '#FFFFFF',
  surface: '#F2F4F6',
  border: '#E5E8EB',
  text: '#191F28',
  textMuted: '#6B7684',
  textDim: '#8B95A1',
  danger: '#F04452',
  warning: '#F59F00',
  positive: '#00A661',
};
```

### 컴포넌트 원칙

- 카드 radius: 18~24
- 입력/버튼 height: 44~52
- 본문 글자: 14~16
- 설명 문구는 필요한 곳에만 한 줄
- 구분선보다 여백과 배경 차이를 사용
- 주요 액션은 blue filled button
- 보조 액션은 gray surface button

### 네비게이션

현재 floating glass tab bar는 브랜드성은 있지만 Toss식과는 다르다.

권장:

- light tab bar
- blur/glass 최소화
- 아이콘+짧은 라벨
- 선택 상태는 blue, 비선택은 gray
- 홈 인디케이터 safe area 위에 자연스럽게 고정

## 6. 문구 원칙

Toss식 문구는 설명보다 결론을 먼저 말한다.

예:

| 현재 가능 문구 | 권장 문구 |
|---|---|
| 관심종목 체크포인트를 먼저 확인하세요 | 오늘 볼 종목을 확인해요 |
| 점수·뉴스·변동·실적 일정을 한 카드에 묶어... | 삭제 |
| 인사이트를 불러오지 못했습니다 | 시그널을 불러오지 못했어요 |
| 표시할 일정이 없습니다 | 예정된 일정이 없어요 |

원칙:

- 제목은 행동 또는 상태를 말한다.
- 보조 설명은 1줄을 넘기지 않는다.
- “이 기능은…” 식 설명은 설정/도움말로 보낸다.

## 7. 실행 단계

### Phase 1. 디자인 토큰과 공통 컴포넌트

목표:

- light theme 추가
- `SignalHeader`, tab bar, segmented control, card, row, button 스타일 기준 통일

작업:

- `constants/theme.ts`에 light/dark semantic token 추가
- `components/signal`에 `SignalSurface`, `SignalPrimaryButton`, `SignalListRow`, `SignalSectionHeader` 추가
- 기존 화면에서 직접 스타일링한 카드/버튼을 점진적으로 교체

### Phase 2. 홈 개편

목표:

- 뉴스 탭 첫 화면을 홈성 경험으로 재구성
- 오늘의 시그널과 관심 브리핑 중복 제거

작업:

- `app/(tabs)/index.tsx`를 HomeFeed 구조로 분리
- 오늘의 시그널 preview, 관심종목 top movers, 관련 근거를 하나의 흐름으로 구성
- 뉴스 목록은 홈 아래 또는 뉴스 전용 탭에서만 노출

### Phase 3. 시세/관심 브리핑 정리

목표:

- 관심종목 기반 개인화 흐름 강화
- 겹침/중복/설명 과다 제거

작업:

- 시세 row 고정 레이아웃
- 관심 브리핑 섹션 재배치
- 같은 종목의 여러 사유를 한 카드로 merge

### Phase 4. 계정/설정 경량화

목표:

- 계정, 알림, 약관, 설정 흐름 단순화

작업:

- 내정보를 `계정 / 보안 / 활동`으로 재정리
- 설정 화면의 설명 문구 축소
- 약관/탈퇴/로그아웃은 하단 링크 형태 유지

### Phase 5. 출시 전 QA

목표:

- 실기기 기준 품질 확보

체크:

- iPhone SE / 13 mini / 15 Pro Max
- 라이트/다크 테마
- Dynamic Type 기본/확대
- 로그인 전후
- 데이터 없음/에러/로딩/느린 API
- 한국어/영어/일본어 줄바꿈

## 8. 리스크

| 리스크 | 설명 | 대응 |
|---|---|---|
| 투자 앱 정체성 약화 | 너무 금융 앱처럼 밝아지면 SIGNAL만의 긴장감이 줄 수 있음 | light-first + market accent를 제한적으로 사용 |
| 홈 정보 과밀 | 오늘의 시그널, 브리핑, 뉴스가 다시 중복될 수 있음 | 홈은 최대 3개 decision card로 제한 |
| 기존 사용자 혼란 | 탭 위치 변경 시 학습 비용 발생 | Phase별 적용, 더보기에서 기존 기능 유지 |
| 구현 범위 증가 | 전체 화면 직접 수정 필요 | 토큰/공통 컴포넌트부터 교체 |

## 9. 우선순위

가장 먼저 할 일:

1. light theme token 추가
2. `SignalHeader`와 tab bar를 Toss식 light shell로 변경
3. 뉴스 탭 상단을 홈 요약 구조로 변경
4. 시세 row 레이아웃 고정
5. 관심 브리핑의 중복 섹션 merge

바로 코드 적용을 시작한다면 Phase 1과 Phase 2를 먼저 진행하는 것이 맞다. 이 두 단계가 끝나야 앱 전체의 첫인상과 매일 방문 이유가 바뀐다.

## 10. 적용 현황

2026-05-16 `toss-client-uiux` 브랜치에서 1차 적용:

- 앱 기본 토큰을 light-first로 전환하되, 시스템/라이트/다크 화면 모드를 지원하도록 확장했다.
- 기본 accent를 Toss 계열 blue로 변경했다.
- 하단 탭바는 glass 설정을 제거하고 white surface, blue selected, gray inactive 기준으로 통일했다.
- 첫 탭은 뉴스가 아닌 홈 역할로 보이도록 라벨과 아이콘을 변경했다.
- `SignalHeader`, 세그먼트 탭, FAB, 에러 박스, 스켈레톤, 광고 placeholder 등 공통 체감 요소를 light shell로 정리했다.
- 더 이상 사용하지 않는 tab bar glass 설정/컴포넌트/저장 서비스를 제거했다.

다음 적용 후보:

1. 홈/뉴스 분리는 적용했다. `app/(tabs)/index.tsx`는 홈, `app/(tabs)/news.tsx`는 원문 뉴스 피드가 담당한다.
2. YouTube는 하단 주 탭에서 제외하고 더보기와 홈 근거 영역으로 이동했다.
3. 관심 브리핑과 종목 상세의 “오늘 볼 이유” 모델을 하나로 합친다.

외부 문서 기준 보정:

- Toss/TDS color role 문서의 grey/blue semantic scale 기준에 맞춰 배경·카드·보조 표면·primary action을 분리한다.
- TDS typography 문서처럼 고정 장식보다 위계와 접근성 스케일을 우선한다.
- TDS button 문서처럼 핵심 행동은 filled primary, 보조 이동은 텍스트/weak action으로 구분한다.
