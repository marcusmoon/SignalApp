# SIGNAL UI/UX Review

상세한 **정량·정성 평가, P0–P3 제안, 로드맵**은 [`SIGNAL-UIUX-EVALUATION.md`](./SIGNAL-UIUX-EVALUATION.md)를 참고한다.

## 판단 기준

SIGNAL은 단순 뉴스 리더가 아니라 수집된 뉴스, 영상, 시세, 캘린더를 바탕으로 사용자가 오늘 확인할 시장 신호를 빠르게 판단하게 하는 앱이다. 화면은 다음 기준으로 정리한다.

- **첫 화면은 판단을 돕는다**: 홈은 전체 목록보다 요약, 변화, 다음 행동을 먼저 보여준다.
- **탭은 목적이 분명해야 한다**: 뉴스, 시세, 홈, 유튜브, 더보기는 서로 중복 설명 없이 각자의 역할을 가진다.
- **필터는 편집 후 한 번에 적용한다**: 선택할 때마다 목록을 다시 불러오지 않고, 완료 또는 시트 닫기에서 적용한다.
- **로딩은 조용해야 한다**: 홈처럼 섹션이 많은 화면에서는 큰 로더보다 작은 상태 표시를 쓴다.
- **설정은 사용 빈도별로 정리한다**: 표시, 알림, 계정, 데이터/운영성 옵션을 한 화면에 나열하지 않는다.

## 현재 평가

### 좋은 점

- 하단 탭이 `뉴스 · 시세 · 홈 · 유튜브 · 더보기`로 명확해졌고, 홈을 중앙에 둔 구조는 제품 방향과 맞다.
- 뉴스/유튜브/시세가 Signal 서버만 바라보는 구조라 운영 안정성과 보안 기준이 좋다.
- 관심종목, 오늘의 시그널, 관련뉴스가 홈에 모이면서 앱의 차별화 방향이 보인다.
- 다크/라이트, 강조색, 하단 메뉴 투명도 등 개인화 기반은 이미 충분하다.

### 개선 필요

- 홈의 각 섹션이 모두 중요해 보여 정보 위계가 약하다. `가장 먼저 봐야 할 신호`와 `근거 콘텐츠`를 더 분리해야 한다.
- 뉴스와 유튜브 필터는 적용/닫기 의미가 모호했고, 버튼 터치 영역도 작았다.
- 더보기와 설정은 기능이 늘어나면서 목록형 나열감이 강하다. 사용자가 자주 쓰는 항목과 운영/고급 항목을 분리해야 한다.
- 일부 화면의 로딩 UI가 화면 목적보다 강하게 보여 실제 콘텐츠보다 로딩 상태가 먼저 눈에 들어온다.
- 내정보는 계정, 약관, 알림, 소셜 연결, 탈퇴가 한 화면에 섞이기 쉬워 작업 단위별 구조가 필요하다.

## 개선 순서

### 1단계: 즉시 개선

- 뉴스/유튜브 필터를 공통 바텀시트로 통일한다.
- 필터 시트는 선택 개수, 전체 선택, 전체 해제, 큰 완료 버튼을 제공한다.
- 닫기와 완료는 같은 의미로 적용되게 하되, 화면 문구는 `완료` 중심으로 정리한다.
- 홈 섹션 로딩은 작은 점/텍스트로 축소한다.
- 시세 탭 30초 폴링은 제거하고 수동 새로고침과 passive cache 중심으로 둔다.

### 2단계: 홈 재정렬

- 홈 상단은 `핵심 시그널 1개 + 보조 시그널 2개` 구조로 압축한다.
- 관심종목은 전체 리스트가 아니라 `큰 변동`, `실적 임박`, `뉴스 집중` 기준으로 묶는다.
- 관련뉴스는 오래된 항목보다 최신성과 관심종목 관련도를 우선한다.
- 뉴스/영상 근거는 같은 카드 규칙을 쓰되, 원문 이동과 탭 이동을 명확히 구분한다.

### 3단계: 더보기/설정 정리

- 더보기는 `내정보`, `설정` 중심으로 유지한다.
- 설정은 `표시`, `알림`, `첫 화면`, `데이터/캐시`, `정보` 그룹으로 재배치한다.
- 고급 운영성 설정은 접힘 섹션으로 내려 기본 사용자 흐름에서 덜 보이게 한다.

### 4단계: 계정/알림 고도화

- 내정보는 `프로필`, `알림`, `보안/소셜`, `약관` 탭 또는 섹션으로 분리한다.
- 탈퇴/로그아웃은 주요 CTA가 아니라 하단 보조 액션으로 유지한다.
- 알림은 단순 목록보다 `읽지 않음`, `인사이트`, `공지`, `계정` 타입별 필터를 둔다.

### 5단계: 출시 품질

- 주요 화면마다 빈 상태, 오류 상태, 로딩 상태를 같은 규칙으로 정리한다.
- API 중복 호출은 탭별 메모리 캐시와 서버 응답 최소화 기준으로 점검한다.
- iOS 실기기 기준으로 터치 영역, 하단 메뉴 위치, 상태바/스플래시 지연을 점검한다.

## 이번 반영 상태

- **1단계 완료**: 뉴스/유튜브 필터는 공통 바텀시트로 통일했고, 선택 개수·전체 선택·전체 해제·큰 완료 버튼을 제공한다. 완료 버튼과 바깥 탭은 모두 적용 후 닫기로 동작한다. 홈 로딩은 작은 인라인 상태로 축소했고, 시세 탭은 자동 폴링 없이 passive cache와 수동 새로고침을 기준으로 둔다.
- **2단계 반영**: 홈의 주요 시그널은 대표 1개와 보조 2개 구조로 위계를 만들고, 관심종목은 관심목록 순서가 아니라 변동률이 큰 항목을 먼저 보여준다.
- **3단계 반영**: 더보기는 내정보와 설정 중심으로 유지하고, 설정은 표시/알림을 앞에 둔 뒤 뉴스·유튜브·시세·캘린더·서버 순으로 정리한다.
- **4단계 반영**: 내정보는 홈·프로필·보안·정보 탭으로 분리하고, 약관/로그아웃/탈퇴는 정보 탭으로 이동했다. 알림함은 전체·중요·인사이트·공지·계정 필터를 제공한다.
- **5단계 반영**: 타입 체크와 diff 검사를 기준 검증으로 삼고, 남은 실기기 검증 항목은 iOS 하단 탭 터치 영역, 필터 시트 높이, 스플래시 이후 첫 렌더링 지연이다.
