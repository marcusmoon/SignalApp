# SIGNAL 서비스 소개서 구성

Google Slides 생성 권한이 열리면 이 구성으로 업로드/변환할 수 있도록 PPTX와 함께 보관합니다.

## 1. SIGNAL

노이즈는 걸러내고, 진짜 시그널만

- 미국 시장·코인·매크로 흐름을 한 화면에서 요약
- 뉴스, 유튜브, 시세, 실적/일정을 연결해 오늘 볼 포인트를 제시

## 2. 문제 정의

정보는 많지만 판단 단서는 흩어져 있다

- 영문 속보, 유튜브, 시세, 실적 일정이 서로 분리되어 있음
- 관심종목 기준으로 지금 확인할 이유를 빠르게 파악하기 어려움
- 사용자는 원문 근거와 한국어 맥락을 동시에 원함

## 3. 제품 방향

원시 피드보다 “오늘 무엇을 봐야 하는가”

- 오늘의 시그널을 앱 최상단에 배치
- 관심 브리핑으로 내 종목의 변화 요약
- 뉴스·영상·시세·일정을 근거로 연결
- 푸시 후보를 서버에서 선별해 알림으로 확장

## 4. 핵심 사용자 기능

투자 정보 소비 흐름을 하나로 묶음

- 뉴스: 글로벌·코인·영상·내 관심 세그먼트와 해시태그
- 시세: 관심·인기·시총·코인 리스트
- 유튜브: 경제 채널 최신순/인기순 큐레이션
- 종목 상세: 가격, 뉴스, 실적, 수집 인사이트 드릴다운

## 5. 오늘의 시그널

서버가 수집 데이터를 기반으로 생성하는 판단 카드

- `market_brief` / `asset_signal` 구조
- `whyNow`, `sourceStats`, `signalDrivers`, `nextSteps` 포함
- 날짜 선택으로 과거 시그널 조회
- LLM provider 연결 시 고도화 가능한 구조

## 6. 관심 브리핑

내 관심종목을 한 번에 훑는 개인 대시보드

- 오늘 체크포인트: 최우선 종목, 최대 변동, 가까운 일정
- 종목별 점수·사유·대표 뉴스·실적 일정을 한 카드에 통합
- API 호출을 배치화해 관심종목이 늘어도 응답 부담을 줄임

## 7. 계정과 알림

SIGNAL 자체 세션 위에 소셜 로그인과 푸시를 연결

- 이메일/비밀번호와 카카오·네이버·구글·Apple 로그인
- 앱 세션은 provider 토큰이 아닌 SIGNAL JWT 사용
- 약관 동의 버전과 시각 저장
- `notification_items` outbox 기반 push 발송 상태 관리

## 8. 어드민 콘솔

수집·운영·사용자 관리를 한곳에서 수행

- 대시보드: 데이터 상태, API 응답, 최근 시그널
- 콘텐츠 수집 관리: Job, 모니터링, 인사이트, 오류 로그
- 앱 사용자: 사용자·디바이스·약관·세션·알림 이력
- 설정: Provider key, 번역, 마켓 리스트, 약관

## 9. 운영 구조

앱은 Signal API만 보고, 서버가 외부 provider를 담당

- Expo 앱 → Signal API → SQLite 기능별 테이블
- API와 worker 분리 운영
- worker는 수집 Job과 notification sender 처리
- 느린 요청/오류 중심 로그와 어드민 API 메트릭 제공

## 10. 출시 준비와 다음 단계

실서비스 전 핵심 QA와 이후 고도화

- 소셜 로그인 실기기 QA, JWT/Push/EAS 설정 확인
- 운영 약관과 개인정보처리방침 등록
- AdMob 운영 ID 또는 광고 비노출 정책 결정
- 출시 후 LLM 기반 시그널 품질 개선과 개인화 알림 확장
